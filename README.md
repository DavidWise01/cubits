# cubits

Twenty-six cubits, AaaA through ZzzZ.

They hold two hosts: [0root.ai](https://0root.ai/) and the public name [davidwise01](https://github.com/DavidWise01). Each public repository sits in the cubit of its first letter. Digits and the dot stay outside the letters: `0root.ai` leaves `0.`, and `davidwise01` leaves `01`.

The sealed list is the public set fetched on 2026-10-21. A page throws if that list no longer partitions into these twenty-six cubits.

`node facts.test.cjs` prints `CUBITS PASS`.

Each page is an analytical cubit: a dark stage with two panels. Neon holds the sculpture. Analytical holds the proof and the complaint. After the count holds, the page criticizes itself in a note built from those same numbers. A note that goes soft, or that cites a different count, throws. The seal does not cover the complaint.
